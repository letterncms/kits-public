# Fathomline

The site of a survey office for moving ground, made with the admin's own blocks, design tokens and the design's scripts.

## Install

```bash
composer require letterncms/fathomline
php cms kit:apply fathomline --dry-run
php cms kit:apply fathomline
```

Or choose **Fathomline** when you install, or under Design → Site Kits.

## What it brings

Nothing yet: the package is ready, and the site goes in before its first release.

## Needs

Nothing beyond the CMS.
