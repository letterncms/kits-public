A shared header, call to action or contact card should have one source. Components let you keep that structure in one place and use properties for the details that vary.

## Choose what should stay connected

Use a component for something that should update across the site. Use a section when you want a starting point that becomes independent after insertion.

| Reuse | What happens after insertion |
| --- | --- |
| Component | Instances stay connected to the source. |
| Section | The inserted blocks become independent. |

## Make a deliberate change

Edit the shared source, review the working copy, then publish. The pages that use the component rebuild with the published version.
